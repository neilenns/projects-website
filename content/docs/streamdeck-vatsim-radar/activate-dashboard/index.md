The activate dashboard action opens a dashboard configured in VATSIM Radar.

## Prerequisites

To use this action you must have the [VATSIM Radar desktop app](https://vatsim-radar.com/download) running.

## Basic configuration

To configure the action to activate a dashboard use the following settings:

| Setting   | Value                                                                                                                   | Example   |
| --------- | ----------------------------------------------------------------------------------------------------------------------- | --------- |
| Title     | The title to show on the action, typically the name of the dashboard.                                                   | `SEA TWR` |
| Dashboard | The dashboard to activate. The list will display all dashboards for the user logged in to the VATSIM Radar desktop app. | `SEA TWR` |

![Screenshot of an activate dashboard action configured, with the title set to SEA TWR and the dashboard dropdown open displaying S16 and SEA TWR.](configuration.png)

## Interactions

The action supports short press.

| Interaction | Description              |
| ----------- | ------------------------ |
| Short press | Activates the dashboard. |
